# Contributing

This list stays valuable by being **curated, not exhaustive**. We list servers a real team
would actually connect — not every toy server in existence.

## Adding a server

Add one line to the right vertical's table:

```
| Name | [owner/repo or vendor link](url) | `official` or `community` | One-line description |
```

Rules:
- ✅ **Real and maintained.** The link must work and the repo/product must be active.
- ✅ **Honest tag.** `official` only if maintained by the vendor or the MCP project. Otherwise `community`.
- ✅ **One line.** Describe what it does, plainly. No sales pitch, no emojis in the description.
- ✅ **Right vertical.** If it fits a business use case not listed, propose a new vertical.
- ❌ No dead repos, no duplicates, no self-promotion of abandoned projects.

## Fixing

Found a dead link, a mislabeled `official`, or a better server? Open a PR — corrections are
as valuable as additions.

## New verticals

Open an issue proposing the vertical and 3+ mature servers that would fill it (e.g. Legal,
Healthcare, HR, Manufacturing).
